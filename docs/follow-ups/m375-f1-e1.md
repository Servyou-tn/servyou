# Follow-ups — F1 + E1 product at 375 (`feat/m375-f1-e1`, 2026-11-05)

## E1 product: the frame's H1, subline and « Adresse » sub-heading

**What** The 375 frame titles the page « Demander ce produit » (ours « Confirmer votre demande », which wraps to 2 lines at 32). It adds a
subline under the H1 (« Renseignez vos coordonnées de livraison. Vous payez à la réception. ») and an « Adresse * » sub-heading over the
four address fields. None have an i18n key; the sub-heading was left out at the first build because its copy was unknown.

**Why deferred** Text changes; asked as Q1–Q3 in `docs/design/m375-f1-e1-deltas.md`.

**Where it lives** `src/app/demander/[id]/_components/ProductRequestScreen.tsx` (H1, subline), `ProductRequestForm.tsx` (sub-heading),
`src/lib/i18n/fr.ts` + `ar.ts` (`demander.title.product` + new keys).

**Trigger** The founder's answers to Q1–Q3.

## E1 product: keyboard order from 1024 to 1279

**What** The summary (with the submit button) now comes after the form fields in the DOM, so on mobile the reading and tab order match the
screen. From 1024 to 1279 the page is still one column with the summary shown first (`lg:max-xl:order-first`), so there the tab order
(fields first) differs from the visual order. Pixels are unchanged.

**Why deferred** No frame for that band; the desktop design pass decides whether 1024–1279 should go two-column earlier or show the
summary last.

**Where it lives** `src/app/demander/[id]/_components/ProductRequestForm.tsx` (the `<aside>`'s `lg:max-xl:order-first`).

**Trigger** The desktop design pass.
