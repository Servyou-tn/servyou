## G5 « Modifier » renders at 16 on desktop (should be 14)

**What** The row's « Modifier » link builds its classes with `cn()`, which merges `text-body-sm` with `text-text-secondary` and drops the size:
it rendered 16 Medium at every width. PR-A5 makes it a plain class string (no merge) with 14 Semi Bold below lg; the desktop classes are
exactly what cn() produced, so desktop still renders 16.

**Why deferred** Changes desktop pixels; asked as Q4 in `docs/design/m375-g9-g5-deltas.md`. Same class of bug as F4's back link.

**Where it lives** `src/app/mes-produits/_components/ProductRow.tsx` — add the base `text-body-sm` to its (now plain) class string.

**Trigger** The design pass (with F4's back link) — founder, 2026-11-04.
