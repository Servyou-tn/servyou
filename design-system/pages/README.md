# Page-specific overrides

Drop a `<page-slug>.md` here only when a page **deviates** from `../MASTER.md`. When
building a page, check for its file first; if present, its rules override MASTER for that
page; otherwise MASTER applies in full.

Keep overrides minimal — list only the deltas (e.g. "this page uses a 2-column hero
instead of the standard single-column form layout"), not a full restatement of MASTER.

No overrides exist yet — every consumer page built so far follows MASTER as-is.
